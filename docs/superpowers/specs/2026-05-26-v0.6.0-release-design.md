## Sections

### 1. `@endpoint` hard-remove

Five-step surgical removal, with `cargo check --workspace` between each step:

1. **Lexer** — `crates/vox-compiler/src/lexer/token.rs`: delete `AtEndpoint` variant and its keyword match arm.
2. **Parser** — `crates/vox-compiler/src/parser/descent/mod.rs:474`: delete `parse_endpoint` function and its dispatch arm.
3. **AST** — `crates/vox-compiler/src/ast/decl/`: delete `EndpointDecl` struct, the `Decl::Endpoint(...)` variant, and every match arm that handles it. The compiler will surface every site needing an update.
4. **Codegen** — `crates/vox-cli/src/commands/{check,compile,db/*}.rs`: drop endpoint-emission branches. Match arms become exhaustive without the `EndpointDecl` variant.
5. **Detectors** — `crates/vox-code-audit/src/detectors/`: remove `AuthEndpointDetector` references in detector arrays + delete the source file. Diagnostic codes `vox/auth/endpoint-missing-decorator` are unreachable once the AST node is gone.

Final verification: `cargo test --workspace`.

### 2. Migration doc

New file `docs/src/reference/migration-0.5-to-0.6.md`. Sections:

- **Removed: `@endpoint` decorator** — replacement: `@public` for HTTP exposure, `@auth` for authentication metadata, `pub fn` for internal-only. Before/after snippet.
- **Added: `@json_as(MyType)` typed JSON deserialization** — replaces ad-hoc casting from `Json`.
- **Added: Raw strings `r"..."` and hash-padded `r#"..."#`** — replaces escape-heavy string literals.
- **Changed: Typed list subscript `list[i]: Option[T]`** — was `T` with panic-on-OOB.
- **Changed: `Json` API is strict-Option** — `get` / `at` / `pointer` + `as_str` / `as_int` / `as_bool` / `has`; legacy `get_str` / `get_int` removed.
- **Added: Intra-project imports** — `import "./foo.vox"` + `pub fn` resolution under `--mode interp`. Typecheck and `--mode script` parity tracked in Phase 2.

Linked from CHANGELOG `[0.6.0]` "Language surface changes" subsection.

### 6. Tag + push

Pre-tag verification:

- `cargo run -p vox-arch-check` (clean)
- `cargo test --workspace` (0 failures)
- `git status` (working tree clean)
- `git rev-list --count origin/main..HEAD == 0` (fully pushed)

Then:

```sh
git tag -a v0.6.0 -m "v0.6.0 — Single-machine multi-agent, no data loss; @endpoint retired; language hardening"
git push origin v0.6.0
```

## Execution order

Sections 1 → 2 → 3 → 4 → 5 → verification → 6. Section 1 is destructive and gates everything else. Each section gets its own atomic commit so a parallel-agent sweep can't merge half-finished work.

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| Parallel-agent commit sweep mid-section | Atomic commit per section; push promptly. |
| Hidden `@endpoint` callers in docs/scripts/examples | `grep -rn '@endpoint' crates/ examples/ scripts/ docs/` before deleting; fix or document each hit. |
| Codegen surprises from `EndpointDecl` removal | Let `cargo check` enumerate; fix each surfaced match arm. |
| Cached plugin dylibs becoming ABI-stale on tag | Already mitigated by T-FIN-3 fix in `13020e9729` — `built_dylib()` invalidates on workspace `Cargo.toml` mtime change. |

## Out of scope

- Phase H "soak" enforcement — the SSOT requirement is "one minor release on `main` without `@endpoint` regressions." That window has elapsed (fixture migration and detector flip have been on `main` for several sessions). Tagging 0.6.0 with `@endpoint` removed in the same commit is consistent with the SSOT.
- A `vox-runtime-container` v0.6 cut — no version coupling; container crate inherits workspace version automatically.
- Release-pipeline wiring (`.github/workflows/release.yml`) — the tag is a soak/gate marker only; published artifacts remain out of scope per `session-handoff-2026-05-25-finalization-pass.md §4 footnote 2`.
