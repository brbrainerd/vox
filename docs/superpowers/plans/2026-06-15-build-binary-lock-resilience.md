# Build / Binary-Lock Resilience & Multi-Agent Build Hygiene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop `git push` (and any dev build) from failing with `failed to remove file …\target\debug\vox.exe — Access is denied (os error 5)` when a stale or parallel `vox` process holds the build output, and make multiple agents sharing one checkout tree co-exist without leaking dangling `vox`/`cargo`/`rustc` processes or wasting redundant compilation.

**Architecture:** Three independently-landable phases. **Phase 1** (headline) makes the relinking build path self-healing: a new `vox ci free-binary` reaper kills only the stale `vox*` processes that lock *this worktree's* `target/`, and the pre-push hook (a) runs that reaper from a *copied* binary on lock failure, and (b) executes the gates from a sidecar copy so a push never self-locks the canonical `vox.exe`. **Phase 2** removes the root leak: managed long-lived daemons are staged into `~/.vox/bin` and launched from there, so a running daemon can never lock a build artifact. **Phase 3** (decision-gated) makes machine-local `sccache` the default for dev agents so redundant compiles across worktrees are deduplicated at the object-file layer.

**Tech Stack:** Rust (`vox-cli`, `vox-cli-core`), the `sysinfo` crate (already a dependency, used by `worktree_gc.rs`), bash hook templates generated by `vox ci install-hooks`, `sccache`.

## Background — verified root cause (read before starting)

The failure chain, confirmed by audit:

1. `git push` runs `.git/hooks/pre-push`, whose entire body is `exec cargo run -q -p vox-cli -- ci pre-push` (generated from `PRE_PUSH_HOOK` in `crates/vox-cli/src/commands/ci/install_hooks.rs:61-68`).
2. After new commits, `cargo` decides `vox.exe` is stale and **relinks** `target\debug\vox.exe`. On Windows the linker must first *delete/overwrite* the existing file.
3. A **different live `vox.exe`** — a leftover foreground run from a crashed/parallel agent, or a long-lived daemon launched from `target\debug\` (e.g. `vox-orchestrator-d`) — still holds an open handle to that file. Windows denies the overwrite → **os error 5** → the push aborts.
4. The only fix today is manual: `Get-Process vox | Stop-Process -Force`, then retry. We did exactly this twice in one session.

**Key facts that constrain the fix (do not re-discover these):**

- The os-error-5 happens *during `cargo run`'s build*, **before any of our Rust `main()` runs**. A reaper compiled into `vox ci pre-push` is therefore too late to save the hook's own relink — the reaper must run *before* `cargo`, from a binary that does **not** live at the path being relinked. A *copy* of `vox.exe` works: Windows allows opening a locked exe for **read/copy**; only delete/overwrite is denied.
- Each worktree already gets its **own** `target/` (`CARGO_TARGET_DIR = { value = "target", relative = true }`, `.cargo/config.toml:34-49`). So any `vox.exe` whose `exe()` path is under *this* worktree's `target/` was, by construction, launched from this worktree — reaping it is safe and never touches a sibling agent's worktree.
- `worktree_gc.rs` already has a `sysinfo`-based process scan (`build_process_haystacks`, `worktree_active`, needles `cargo|rustc|…|vox`). Reuse its *pattern*, but the new reaper is **scoped to the current target dir** and actually **kills** rather than merely *protecting*.
- `pre_push.rs` already has `running_as_vox_exe()` (line 803) and skips nextest for `vox-cli` when true (line 793). That mitigates *sub*-builds, not the top-level hook relink.
- `resolve_managed_binary_path` (`crates/vox-cli-core/src/daemon_ipc/process_supervision.rs:56-79`) resolves a managed binary as: sibling-of-current-exe → `~/.vox/bin/<exe>` → PATH → bare name. During dev the sibling is `target/debug/`, which is exactly what couples a daemon's lock to the build output.
- sccache gives **91.9% warm same-path hits** but **0% cross-worktree hits** (`docs/src/ci/shared-compile-cache.md:67-74`); it is **opt-in only** and must run with `CARGO_INCREMENTAL=0`.

```rust
fn should_reap(exe: &Path, target_dir: &Path, pid: u32, current_pid: u32) -> bool {
    if pid == current_pid {
        return false;
    }
    // Normalize both sides to lowercase string compare — robust on Windows
    // (case-insensitive FS, mixed separators) without canonicalize() (which
    // fails on a locked/transient path).
    let norm = |p: &Path| p.to_string_lossy().to_lowercase().replace('\\', "/");
    let exe_s = norm(exe);
    let target_s = norm(target_dir);
    if !exe_s.starts_with(&format!("{target_s}/")) {
        return false;
    }
    // Only `vox` and its managed siblings (vox-orchestrator-d, …) are reapable.
    let file = exe
        .file_name()
        .map(|n| n.to_string_lossy().to_lowercase())
        .unwrap_or_default();
    file == "vox"
        || file == "vox.exe"
        || file.starts_with("vox-") && !file.ends_with("-build")
}
```

```rust
use anyhow::Result;
use sysinfo::System;

/// One stale process holding `target/`.
struct LockingProc {
    pid: u32,
    exe: std::path::PathBuf,
}

/// Scan all processes and return those whose executable lives under `target_dir`
/// and is reapable (`should_reap`), excluding the current process.
fn scan_locking_pids(target_dir: &Path) -> Vec<LockingProc> {
    let current = std::process::id();
    let sys = System::new_all();
    let mut out = Vec::new();
    for (pid, proc_) in sys.processes() {
        let Some(exe) = proc_.exe() else { continue };
        let pid_u = pid.as_u32();
        if should_reap(exe, target_dir, pid_u, current) {
            out.push(LockingProc {
                pid: pid_u,
                exe: exe.to_path_buf(),
            });
        }
    }
    out
}

/// Kill the given pid. Best-effort: a process may already be gone.
fn kill_pid(pid: u32) -> bool {
    let sys = System::new_all();
    sys.process(sysinfo::Pid::from_u32(pid))
        .map(|p| p.kill())
        .unwrap_or(false)
}

/// `vox ci free-binary` entry. `target` defaults to `<root>/target`.
/// Dry-run by default; `apply` kills the stale lockers.
pub fn run(root: &Path, target: Option<std::path::PathBuf>, apply: bool) -> Result<()> {
    let target_dir = target.unwrap_or_else(|| root.join("target"));
    let locking = scan_locking_pids(&target_dir);
    if locking.is_empty() {
        println!("free-binary: no stale vox processes hold {}", target_dir.display());
        return Ok(());
    }
    for lp in &locking {
        if apply {
            let ok = kill_pid(lp.pid);
            println!(
                "free-binary: {} pid={} exe={}",
                if ok { "killed" } else { "could-not-kill" },
                lp.pid,
                lp.exe.display()
            );
        } else {
            println!(
                "free-binary: [dry-run] would kill pid={} exe={}",
                lp.pid,
                lp.exe.display()
            );
        }
    }
    Ok(())
}
```

```rust
const PRE_PUSH_HOOK: &str = r#"#!/usr/bin/env bash
# File: .git/hooks/pre-push
# Generated by `vox ci install-hooks`. Do not edit; regenerate via the command.
# Body delegates to `vox ci pre-push` per AGENTS.md VoxScript-First Glue Code.
#
# Windows binary-lock resilience (os error 5 on relink):
#  1. `cargo build` relinks target/debug/vox(.exe). If a stale/parallel vox
#     process holds it, the relink is denied. We copy the (still readable) vox
#     to a reaper sidecar, run `ci free-binary --apply` to kill ONLY stale vox
#     procs holding THIS worktree's target, then retry the build once.
#  2. We run the gates from a SIDECAR COPY (vox-prepush) so this push never
#     itself locks the canonical vox.exe for the next push.
set -u
EXE=""
case "$(uname -s 2>/dev/null)" in MINGW*|MSYS*|CYGWIN*) EXE=".exe";; esac
VOX="./target/debug/vox${EXE}"

reap() {
  # Copy is allowed even while the target is locked (read share); the copy then
  # kills the stale lockers. A stable ~/.vox/bin/vox is preferred if present.
  local reaper="./target/debug/vox-reaper${EXE}"
  if [ -x "$HOME/.vox/bin/vox${EXE}" ]; then
    "$HOME/.vox/bin/vox${EXE}" ci free-binary --target ./target --apply || true
  elif [ -f "$VOX" ]; then
    cp -f "$VOX" "$reaper" 2>/dev/null && "$reaper" ci free-binary --target ./target --apply || true
  fi
}

if ! cargo build -q -p vox-cli; then
  echo "pre-push: build failed (possible vox.exe lock) — reaping stale vox procs and retrying"
  reap
  cargo build -q -p vox-cli || { echo "pre-push: build still failing after reap"; exit 1; }
fi

# Run gates from a sidecar copy so the canonical vox.exe stays free to relink.
SIDE="./target/debug/vox-prepush${EXE}"
cp -f "$VOX" "$SIDE" 2>/dev/null || SIDE="$VOX"
exec "$SIDE" ci pre-push
"#;
```

```rust
/// Copy `src` into `dest_dir` (preserving file name) when the destination is
/// missing or older than `src`. Returns the staged path. Used so long-lived
/// daemons run from `~/.vox/bin` instead of `target/debug` — a running daemon
/// must never hold a lock on a build artifact (Windows relink os-error-5).
pub fn stage_binary(src: &Path, dest_dir: &Path) -> std::io::Result<PathBuf> {
    let name = src
        .file_name()
        .ok_or_else(|| std::io::Error::other("source has no file name"))?;
    let dest = dest_dir.join(name);
    std::fs::create_dir_all(dest_dir)?;
    let needs_copy = match (std::fs::metadata(&dest), std::fs::metadata(src)) {
        (Ok(d), Ok(s)) => match (d.modified(), s.modified()) {
            (Ok(dm), Ok(sm)) => sm > dm,
            _ => true,
        },
        _ => true, // dest missing
    };
    if needs_copy {
        std::fs::copy(src, &dest)?;
    }
    Ok(dest)
}
```

```rust
/// Resolve the path to launch a long-lived managed daemon from, guaranteeing it
/// is NOT under a `target/` build dir. If `src` (typically the target/debug
/// sibling) exists, stage it into `dest_dir` (`~/.vox/bin`) and return that.
/// Otherwise fall back to whatever `resolve_managed_binary_path` finds.
pub fn resolve_or_stage_daemon(src: &Path, dest_dir: &Path) -> std::io::Result<PathBuf> {
    if src.exists() {
        return stage_binary(src, dest_dir);
    }
    let name = src
        .file_name()
        .and_then(|n| n.to_str())
        .unwrap_or_default();
    Ok(resolve_managed_binary_path(name))
}
```

```rust
fn advise(sccache_on_path: bool, rustc_wrapper: Option<&str>, cargo_incremental: Option<&str>) -> Vec<String> {
    let mut out = Vec::new();
    if !sccache_on_path {
        out.push("sccache is not installed — `cargo install sccache` to dedup compiles across worktrees (91.9% warm hits same-path).".into());
        return out;
    }
    let wrapper_is_sccache = rustc_wrapper.map(|w| w.contains("sccache")).unwrap_or(false);
    if !wrapper_is_sccache {
        out.push("sccache installed but unused — set RUSTC_WRAPPER=sccache (per-user ~/.cargo/config.toml [build] rustc-wrapper, not the tracked repo config).".into());
    }
    if wrapper_is_sccache && cargo_incremental != Some("0") {
        out.push("sccache active but CARGO_INCREMENTAL is not 0 — incremental artifacts are uncacheable and fork cache keys. Set CARGO_INCREMENTAL=0.".into());
    }
    out
}

pub fn run(_root: &std::path::Path) -> anyhow::Result<()> {
    let on_path = which_sccache();
    let wrapper = std::env::var("RUSTC_WRAPPER").ok();
    let incremental = std::env::var("CARGO_INCREMENTAL").ok();
    let advice = advise(on_path, wrapper.as_deref(), incremental.as_deref());
    if advice.is_empty() {
        println!("build-cache-doctor: sccache healthy (wrapper set, incremental off).");
    } else {
        for line in advice {
            println!("build-cache-doctor: {line}");
        }
    }
    Ok(())
}

fn which_sccache() -> bool {
    // PATH probe without spawning; mirrors path_lookup in process_supervision.
    let exe = if cfg!(windows) { "sccache.exe" } else { "sccache" };
    std::env::var_os("PATH")
        .map(|paths| std::env::split_paths(&paths).any(|d| d.join(exe).is_file()))
        .unwrap_or(false)
}
```
