**Goal:** a language user, a harness user and a contributor can each install only what they need — and end users need neither cargo nor npm.

**Spec:** [`../specs/2026-09-04-distribution-and-plugin-architecture.md`](../specs/2026-09-04-distribution-and-plugin-architecture.md) §9, §3

**You own:** `crates/vox-cli/Cargo.toml`, `crates/vox-config/Cargo.toml`, `crates/vox-codegen/Cargo.toml`, `crates/vox-sql/Cargo.toml`, `crates/vox-langtool/`, `crates/vox-lsp/Cargo.toml`, `contracts/distribution/profiles.v1.yaml`

## Global constraints

See the index. Non-negotiable everywhere: assert on the artifact never the exit code (`cmd > /tmp/x.log 2>&1; echo $?`); `cargo test -p X` needs `--all-targets` or it can report "0 passed" when tests live in a bin target; guards must run on macOS (no `grep -oP`); never execute a downloaded binary or set `com.apple.quarantine`.

## The three audiences

| | A. Language user | C. Harness user | B. Contributor |
|---|---|---|---|
| Wants | writes `.vox`, compiles, runs | agentic CLI + Axis; does not care about the language | develops Vox itself |
| Identity | `voxlang` | `vox-cli` + `Vox.Axis` | **none — not a package** |
| Must NOT need | orchestrator, model catalog, GPU | the compiler surface | — |

**B is deliberately not a package.** No package manager should be the contributor path.

## Measured blockers

| # | Blocker |
|---|---|
| B1 | `vox-cli` has 125 direct deps, only 16 optional, **none of them AI**. `vox-orchestrator`, `vox-populi`, `vox-actor-runtime`, `vox-llm-egress`, `vox-db`, `vox-search` are all non-optional. 25 features, all additive; no subtractive path. |
| B2 | **`vox-compiler` transitively links an OpenAI client**: `vox-compiler` → `vox-config` → `vox-llm-egress` → `vox-openai`, all non-optional. The deepest coupling; break it first. |
| B3 | `vox-codegen` → `vox-sql` → `vox-db`, non-optional — this regressed `vox-langtool`'s previously-claimed DB-free property. |
| B4 | `vox-gui` → `vox-cli`, so Axis links the entire compiler (96 workspace crates). |
| B5 | `vox-orchestrator-mcp` → `vox-compiler`, by design (it exposes compiler tools). |
| B11 | **`crates/vox-langtool` already exists** — "DB-free CLI for writing in the Vox language", 34 workspace crates vs `vox-cli`'s 94 — and is in no tier and no release workflow. |

Two in-tree precedents to copy: `vox-lsp`'s default-on `db` feature with an explicit rationale, and `vox-langtool`'s `default-features = false` path dep.

## Task 1: Break `vox-config` → `vox-llm-egress` (B2)
- [ ] Write a failing test: `cargo tree -p vox-compiler` contains no `vox-openai`.
- [ ] Make the dep optional behind a feature that the compiler does not enable.
- [ ] This is the highest-value single change in the plan — it is what makes a language-only artifact conceivable at all.

## Task 2: Break `vox-codegen` → `vox-sql` → `vox-db` (B3)
- [ ] Failing test: `cargo tree -p vox-langtool` contains no `vox-db`.
- [ ] Gate behind a feature; `vox-langtool` opts out.

## Task 3: Ship `vox-langtool` (B11)
- [ ] Verify it builds — that is currently UNVERIFIED.
- [ ] Add it to the tier `binaries` list and request a release-matrix entry from P4.

## Task 4: Reconcile the two taxonomies
- [ ] `profiles.v1.yaml` tiers (`minimal`/`default`/`full`) and `catalog.toml` bundles (`vox-base`/`vox-fullstack`/…) share **no ids, no cross-reference, no code path**. Pick one; make the other derive from it or delete it.
- [ ] `minimal` and `default` currently ship an identical `binaries` list, so "compiler / language CLI only" is false.

## Task 5: De-bleed the personas
- [ ] `vox-cli/src/main.rs:115` tells users `cargo install --path crates/vox-ml-cli` — an installed user has no `crates/`. Fix every such string. *(P1 owns the ML-side ones.)*
- [ ] `vox run` shells out to `cargo run` and, with a frontend, to `pnpm`. **A language user should not need either.** Either bundle what is needed or state the dependency honestly at install time.
- [ ] `vox doctor` fails all three personas identically on missing cargo/node/pnpm; make the expectation persona-aware.

## Verification

- [ ] `cargo check -p vox-langtool --all-targets` exit 0 with counts.
- [ ] Workspace still builds: `cargo check --workspace --all-targets`.
